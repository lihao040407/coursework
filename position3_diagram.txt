位置3：第一棒检查 - 代码结构图
============================================

原来的代码结构：
--------------------------------------------
if ( pPrevA == NULL)  
    thrd_print(...started...);  ← 只有一行


修改后的代码结构：
--------------------------------------------
if ( pPrevA == NULL) {  ← 改成代码块 { }
    
    ┌─────────────────────────────────────┐
    │ 步骤1：找到队伍索引                 │
    │ int teamIndex = -1;                │
    │ for (循环找队伍名称) {              │
    │     if (匹配) {                     │
    │         teamIndex = i;              │
    │     }                               │
    │ }                                   │
    └─────────────────────────────────────┘
              ↓
    ┌─────────────────────────────────────┐
    │ 步骤2：检查是否被取消资格           │
    │ if (teamIndex >= 0 &&              │
    │     teamDisqualified[teamIndex]) { │
    │     打印"已取消"                    │
    │     return;  ← 退出，不比赛          │
    │ }                                   │
    └─────────────────────────────────────┘
              ↓
    ┌─────────────────────────────────────┐
    │ 步骤3：如果正常，继续比赛           │
    │ thrd_print(...started...);          │
    └─────────────────────────────────────┘
    
}  ← 代码块结束


============================================
关键理解点：
============================================

1. 为什么要找 teamIndex？
   答：因为 teamDisqualified 是一个数组
      teamDisqualified[0] = Jamaica 的状态
      teamDisqualified[1] = United States 的状态
      需要知道是哪个队伍，才能检查对应的数组元素

2. 为什么要检查 teamDisqualified[teamIndex]？
   答：如果之前有人掉棒了，这个值就是 true
      第一棒看到 true，就知道队伍被取消了，不应该开始

3. 为什么要 return？
   答：如果队伍被取消，第一棒不应该继续比赛
      return 会退出这个函数，线程结束

4. 什么时候执行位置3？
   答：只有当 pPrevA == NULL 时（第一棒）
      非第一棒不会执行这段代码
