位置4：非第一棒接棒后检查 - 流程图
============================================

非第一棒运动员接棒后
    ↓
┌─────────────────────────────────────┐
│ 步骤1：找到队伍索引                 │
│ int teamIndex = -1;                │
│ for (找队伍名称) {                  │
│     if (匹配) teamIndex = i;        │
│ }                                   │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ 步骤2：检查是否已被取消资格         │
│ if (teamDisqualified[teamIndex]) { │
│     打印"已取消"                    │
│     return;  ← 退出                 │
│ }                                   │
└─────────────────────────────────────┘
    ↓
┌─────────────────────────────────────┐
│ 步骤3：生成随机数（0-100）           │
│ float batonChance = 随机数;         │
└─────────────────────────────────────┘
    ↓
    ├─ batonChance < 5.0
    │   ↓
    │   ┌─────────────────────────────┐
    │   │ 掉棒！                      │
    │   │ teamDisqualified = true    │
    │   │ 打印"BATON DROP!"          │
    │   │ return（退出）              │
    │   └─────────────────────────────┘
    │
    ├─ 5.0 <= batonChance < 20.0
    │   ↓
    │   ┌─────────────────────────────┐
    │   │ 失误！                      │
    │   │ 计算延迟时间                │
    │   │ 打印"BATON FUMBLE!"         │
    │   │ sleep（延迟）               │
    │   │ 继续比赛                    │
    │   └─────────────────────────────┘
    │
    └─ batonChance >= 20.0
        ↓
        ┌─────────────────────────────┐
        │ 正常                        │
        │ 继续比赛（无延迟）           │
        └─────────────────────────────┘

============================================
关键点：
============================================

1. 位置4必须在 else 块内部
   - 因为只有非第一棒才会接棒
   - 第一棒没有接棒，所以不需要检查掉棒

2. 必须在接棒之后检查
   - 先接棒，再检查是否掉棒/失误
   - 顺序：接棒 → 检查 → 处理

3. 三种情况：
   - 掉棒（0-5%）：最严重，队伍取消资格
   - 失误（5-20%）：有延迟，但继续比赛
   - 正常（20%以上）：无影响，继续比赛
